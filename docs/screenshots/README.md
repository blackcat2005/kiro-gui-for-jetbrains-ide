# Marketplace screenshots

Put the images for the JetBrains Marketplace page here. Marketplace does not read them from the repo or the plugin zip:
upload them by hand under the plugin's page → **Media**. This folder only keeps the originals.

- PNG or JPG, about 1280 px wide or more, same size for all of them if possible.
- Name them in the order they should appear: `01-chat.png`, `02-diff-review.png`, ...
- Use a project with nothing private in the editor, file tree, chat or paths.

Ideas for the set:

1. The chat answering, with the transcript and the composer
2. A diff to review before Kiro changes a file
3. Attachments (@ file picker, pasted image, selected code)
4. The Jobs panel with a background job or a debugger stop
5. Library: agents, MCP servers, sessions
6. Settings → Tools → Kiro
